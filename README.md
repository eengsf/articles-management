# 📝 Articles Management System

A web-based Article Management System built with **React**, **React Hook Form**, **Zod**, **Tiptap Editor**, and **Tailwind CSS**.

Live Demo: [articles-management-nine.vercel.app](https://articles-management-nine.vercel.app)

---

## 🚀 Features

- Create and edit rich text articles
- Article listing with preview
- Form validation using Zod
- Modern, responsive UI with Tailwind CSS
- Built with best practices using React and hooks

---

## 🛠️ Tech Stack

- **React** – Frontend library
- **React Hook Form** – Form state management
- **Zod** – Schema validation
- **Tiptap** – Rich text editor
- **Tailwind CSS** – Utility-first CSS framework
- **Vite** – Development server and bundler
- **Vercel** – Deployment platform
